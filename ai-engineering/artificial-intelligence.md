# Artificial Intelligence
Artificial Intelligence (AI) is the field of building systems that can perform tasks that usually require human intelligence, such as learning, reasoning, decision-making, pattern recognition, and problem-solving.

AI includes multiple approaches, including rule-based (symbolic) systems, search and planning methods, probabilistic reasoning, and data-driven methods such as machine learning.

## Machine Learning
ML is a subset of AI that uses algorithms to detect patterns in data, allowing systems to learn and adapt without being explicitly programmed for every task.

Common machine learning paradigms include:

#### Supervised Learning
A model is trained on labeled data. For example, an email spam detection model is trained on a large labeled dataset indicating whether each email is spam or not.

#### Unsupervised Learning
A model is trained on unlabeled data to discover hidden patterns. For example, customer segmentation can identify groups such as budget shoppers and luxury buyers from grocery purchase data.

#### Reinforcement Learning
A model (agent) takes actions in an environment and receives rewards or penalties as feedback to learn better behavior over time.
For example, in autonomous driving simulation: "Steer left → Crash (penalty), stay in lane → Safe (reward)".

#### Self-Supervised Learning
A model learns from the structure of unlabeled data by generating its own training signals. This is widely used in modern language and vision models.
For example, if a sentence is "The cat sat on the ___", the model learns by predicting the missing word ("mat") using the surrounding words as context.

## Deep Learning
DL is a subset of ML that uses neural networks for advanced data processing and analytical tasks.
It leverages multiple layers of artificial neural networks to extract higher-level features from raw input data.

Common deep learning categories include:

- Computer Vision models (for images and video)
- Natural Language Processing models (for text and language)
- Speech models (for voice and audio)
- Recommendation models (for personalized suggestions)

Example:
An image classification model can learn from thousands of labeled photos to identify whether a picture contains a cat or a dog.


## Generative AI
Generative AI is a class of deep learning models that creates new content such as text, images, audio, video, or code from a given input.
Trained on large datasets, these models learn patterns and generate coherent outputs for tasks like summarization, translation, design, and coding assistance.

Common Generative AI categories include:

- Text generation (chatbots, summarization, translation)
- Image generation (text-to-image art and design)
- Audio generation (speech synthesis, music generation)
- Video generation (text-to-video content creation)
- Code generation (coding assistants)
- Multimodal generation (combining text, image, audio, or video)

Example:
If a user prompts, "Write a short email to thank a customer for their purchase," a generative AI model can create a complete, polite email draft in seconds.
